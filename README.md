# Cisco Packet Tracer Web & Mobile Edition

محاكي شبكات متكامل شبيه ببرنامج **Cisco Packet Tracer 8.2.2** يعمل بالكامل داخل المتصفح (Web & Mobile Edition) بدون الحاجة لتثبيت أي برامج!

![Preview](art/app.png)

## ✨ المميزات الرئيسية (Features)
- 🌐 **يعمل 100% في المتصفح**: متوافق مع أجهزة الكمبيوتر والهواتف الذكية (iOS & Android).
- 📱 **تحكم كامل ومحسّن للجوال**:
  - تحريك الخلفية ومساحة العمل بحرية بسحب الإصبع في أي مكان فارغ (**Pan Canvas**).
  - إمكانية التكبير والتصغير والتحريك بإصبعين (**Pinch to Zoom**).
  - شريط تحكم عائم للأجهزة تحت إبهام المستخدم.
- 🔲 **تحديد متعدد (Multi-Select)**:
  - أداة تحديد بالسحب (Marquee Selection) لتحديد أكثر من جهاز معاً.
  - إمكانية نقل مجموعة أجهزة مع توصيلاتها دفعة واحدة.
  - حذف جماعي للمحدد.
- 📋 **نسخ ولصق متطور (Copy & Paste)**:
  - نسخ ولصق الأجهزة المحددة مع الاحتفاظ بكافة الإعدادات والتوصيلات الداخلية بينها.
  - إمكانية نسخ ومشاركة كود العمل الجاهز بالكامل كملف JSON ودمجه في أي مساحة عمل أخرى.
- 💻 **سيسكو IOS CLI حقيقي**:
  - دعم أنماط User EXEC، Privileged EXEC، Global Config، Interface، Sub-interface، Router Config، Line Config.
  - دعم أوامر التوجيه (Routing): Static Routes, OSPF v2, RIP v2.
  - دعم السويتشات: VLANs, 802.1Q Trunk, Port-Security, STP (Spanning Tree).
  - خدمات الشبكة: DHCP Server & Pools, DNS, Web HTTP Server, NAT/PAT, ACLs.
- 🧪 **مختبرات وتحديات جاهزة (Labs & CCNA Challenges)**.
- 🚀 **أدوات فائقة**:
  - فاحص ومساعد الذكاء الاصطناعي (AI Copilot).
  - حاسبة وتخطيط الـ VLSM والشبكات.
  - محلل الحزم المباشر (Web Wireshark).
  - جدول العناوين وتوثيق الشبكة التلقائي.

## 🚀 تشغيل الموقع عبر GitHub Pages
المشروع مبني بتقنيات الويب القياسية (Pure HTML5, CSS3, Vanilla JavaScript) ويعمل مباشرة وبشكل مجاني على **GitHub Pages**:
1. ارفع المشروع إلى مستودع (Repository) في GitHub.
2. ادخل على **Settings** > **Pages**.
3. تحت **Branch**، اختر `main` واضغط **Save**.
4. سيظهر لك رابط الموقع المباشر في غضون ثوانٍ!

## 💻 التشغيل محلياً (Local Run)
يمكنك تشغيله محلياً عبر أي خادم ويب ثابت (أو عبر Node.js):
```bash
node server.js
```
ثم افتح الرابط: `http://localhost:3000`
