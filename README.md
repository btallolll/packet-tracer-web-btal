# Cisco Packet Tracer Web — النسخة السحابية المتطورة للويب والجوال

محاكي شبكات تفاعلي وسحابي متكامل مستوحى من بيئة **Cisco Packet Tracer**، مصمم ليعمل بالكامل داخل المتصفح بأحدث معايير الويب دون الحاجة لتثبيت أي برامج، مع دعم كامل ومخصص لشاشات الهواتف وأجهزة الكمبيوتر.

![Preview](art/app.png)

---

## 🌟 أبرز ما يميز هذا الإصدار (Key Highlights)

- 📱 **واجهة مخصصة ومريحة للجوال (Mobile-First UI)**:
  - مساحة عمل واسعة تتجاوز 85% من الشاشة.
  - درج سفلي ذكي قابل للطي بلمسة واحدة (`Collapsible Drawer`) لتصفح الراوترات والسويتشات والكيابل دون حجب الشبكة.
  - تكبير وتصغير سلس وحر بإصبعين (**Pinch to Zoom**) وسحب انسيابي في أي مكان (**Pan Canvas**) بدون أي انتقال مفاجئ أو اهتزاز.
  - كبسولة تحكم مدمجة وعصرية في الركن العلوي، وشريط أدوات سريع ومريح للإبهام.
- ⚡ **البدء الفوري من الصفر (Blank Canvas by Default)**:
  - مساحة بيضاء نظيفة ومستقرة تسمح للمهندس ببناء الشبكة خطوة بخطوة من البداية.
  - إمكانية فتح المعامل الجاهزة (VLANs, OSPF, DHCP) في أي لحظة من القوائم السريعة.
- 💻 **محاكي Cisco IOS CLI متقدم**:
  - سطر أوامر تفاعلي يدعم أوامر التكوين الأساسية والمتقدمة.
  - دعم أنماط سيسكو: `User EXEC`, `Privileged EXEC`, `Global Config`, `Interface`, `VLAN Database`, `Router Config`.
  - بروتوكولات التوجيه: Static Routing, OSPFv2, RIPv2.
  - خدمات السويتش والشبكة: VLANs, 802.1Q Trunking, Spanning Tree (STP), Port Security, DHCP Pools, DNS, Web Server, NAT/PAT.
- 🔲 **أدوات تحديد وتحكم جماعي (Multi-Select & Bulk Actions)**:
  - تحديد متعدد بالسحب أو اللمس ونقل مجموعات كاملة مع أسلاكها.
  - نسخ ولصق الأجهزة مع كامل إعداداتها، أو تصدير الطوبولوجيا ككود ومشاركتها.
- 🛡️ **حماية ضد أدوات الاستنساخ الآلي (Anti-Scraping / Anti-AI Shield)**:
  - حماية ذكية هادئة في الخلفية للمحافظة على جهد التطوير والملكية الفكرية من برامج التكشيط الآلية.
- 🚀 **أدوات فائقة مدمجة**:
  - 🤖 فاحص وتشخيص بالذكاء الاصطناعي (AI Copilot).
  - 🧮 حاسبة شبكات و VLSM تلقائية.
  - 🦈 محلل حزم مباشر شبيه بـ Web Wireshark.
  - 📊 توثيق وجدول عناوين IP بضغطة زر.

## 🚀 التشغيل المباشر عبر GitHub Pages

المشروع مبني بتقنيات الويب النقية السريعة (Pure HTML5, CSS3, Vanilla JS):
1. اذهب إلى إعدادات المستودع **Settings** > **Pages**.
2. تحت قسم **Build and deployment**، اختر الفرع `main` والمجلد `/ (root)`.
3. اضغط **Save** وسيصبح الموقع متاحاً على الإنترنت برابطك الخاص.

---

## 💻 التشغيل محلياً (Local Run)

باستخدام Node.js:
```bash
node server.js
```
ثم افتح: `http://localhost:3000`
